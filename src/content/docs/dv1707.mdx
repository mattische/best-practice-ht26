## Kursen i korthet

Ett gruppprojekt där studenterna bygger en frontend-applikation i React utifrån en kravspecifikation. Arbetssättet är agilt och iterativt, uppdelat i sprintar.

- User stories, tasks och estimering.
- GitHub Flow med pull requests och code review.
- Två inlämningar per sprint: en gemensam och en individuell reflektion.

| Sprint | Längd | Fokus |
|---|---|---|
| Sprint 0 | 1 vecka | Förberedelse och setup: gruppen etableras, verktyg och ramverk väljs, repo och planeringsverktyg sätts upp. Ingen kodning i fokus |
| Sprint 1 | 2 veckor | Första implementationssprinten: sprint planning, user stories och tasks, start med React, GitHub Flow med code review. **Lysa besöker** |
| Sprint 2 | 2 veckor | Fortsatt implementation. Nytt: estimering och tidsloggning |
| Sprint 3 | 2 veckor | Fortsatt implementation, förfinade processer, kravspecen kan uppdateras |
| Sprint 4 | 2 veckor | Sista större implementationssprinten, förberedelser inför slutleveransen |
| Sprint 99 | 1 vecka | Leverans och examination: slutleverans av produkten (MVP), grupprapport, kodgranskning av en annan grupp, live-presentation och individuell dokumentation |

## Lysa i sprint 1

[Sprint 1](https://dbwebb-projfront.github.io/sprint1/) är första implementationssprinten. Gruppen sätter upp sitt arbetssätt och börjar med React, och det var då Lysa kom.

Lysa är en svensk fondrobot med över 220 000 kunder. Vi fick besök av kontorschefen och en utvecklare som tidigare läst på BTH. De visade hur de organiserar och strukturerar sina React-projekt. Föreläsningen finns som video på sprintsidan.
