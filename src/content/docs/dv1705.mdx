## Kursen i korthet

Design och användarupplevelse med JavaScript. Studenterna arbetar individuellt genom momenten och bygger en webbshop med fokus på användarupplevelse (UX), från förstasida via färg, typografi, interaktivitet och formulär till återanvändbar kod och AI-stöd.

| Moment | Fokus |
|---|---|
| kmom01 | Kom igång: förstasida till webbshopen |
| kmom02 | Färg och typografi |
| kmom03 | Interaktivitet: varukorg med JavaScript |
| kmom04 | Formulär och orderhantering |
| kmom05 | Webbkomponenter |
| kmom06 | AI för bättre användarupplevelse |
| kmom10 | Projekt |

## Inter IKEA i kursen

[Kmom05](https://dbwebb-jsux.github.io/kmom05/) handlar om webbkomponenter, det vill säga att strukturera JavaScript så att det kan återanvändas. Momentet introducerar konceptet för studenterna, och då fick vi besök av Inter IKEA.

Två alumner som arbetar som utvecklare hos Inter IKEA berättade hur och varför de använder web components. Besöket finns som inspelning i momentet, tillsammans med läsning, en övning och en uppgift där studenterna bygger en webbkomponent i sin webbshop.
