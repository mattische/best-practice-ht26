## Inter IKEA i kursen

[Kmom05](https://dbwebb-jsux.github.io/kmom05/) handlar om webbkomponenter, det vill säga att strukturera JavaScript så att det kan återanvändas. Momentet introducerar konceptet för studenterna, och då fick vi besök av Inter IKEA.

Två alumner som arbetar som utvecklare hos Inter IKEA berättade hur och varför de använder web components. Besöket finns som inspelning i momentet.

Så arbetar studenterna i momentet:

- **Läsa:** kapitlet "Lists of Things" i kurslitteraturen, och MDN om web components och custom elements.
- **Öva:** de bygger produktlistningen i webbshoppen som en komponent per produkt. Idén är att kapsla in kod med ett ansvarsområde för att kunna återanvända den (DRY, SRP och encapsulation). De mäter också prestanda och tillgänglighet med Google Lighthouse.
- **Uppgift:** i [Webbshoppen del 5](https://dbwebb-jsux.github.io/uppgifter/webbshoppen_del_5/) gör de om varukorgens orderrader till webbkomponenter, skickar data till dem som JSON och hanterar ökning, minskning och borttagning i komponentens klass. De skriver också en analysrapport med Lighthouse-mätningar av två webbplatser.
- **Reflektion:** om hur det var att jobba med web components och om det ger en bättre struktur. Inlämning sker som en pull request.
