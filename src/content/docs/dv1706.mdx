## Kursen i korthet

Webbapplikationer för mobila enheter. Studenterna arbetar individuellt genom momenten och bygger en webbapplikation för mobila enheter med relevanta tekniker och koncept, som router, JWT, enhets-API:er, realtid och PWA.

| Moment | Fokus |
|---|---|
| kmom01 | Egen router, navigation utan sidomladdning |
| kmom02 | Formulär och CRUD |
| kmom03 | Autentisering med JWT |
| kmom04 | Mobila enheters styrkor (GeoLocation, MediaCapture) |
| kmom05 | Realtidskommunikation |
| kmom06 | Progressive Web Apps |
| kmom10 | Projekt |
